# ReuseAccess

Reusable accessible React + TypeScript UI component library with live CoinGecko integration.

## Highlights
- 8 reusable components with keyboard-friendly interactions and ARIA support
- Live cryptocurrency data from CoinGecko
- React.memo optimization for repeated prop updates
- Axe-core accessibility tests
- GitHub Actions CI

## Run
```bash
npm install
npm run dev
```

## Test
```bash
npm test
npm run build
```
