# ReuseAccess

A reusable accessible React + TypeScript component library with a production-style market dashboard and live CoinGecko integration.

## Engineering highlights
- 8 reusable components with semantic HTML, ARIA support, keyboard-friendly interactions and responsive layouts
- React Query for asynchronous server-state management, request caching, retries, stale-time control and explicit refresh
- CoinGecko REST integration with loading, error, retry and background-fetch states
- React.memo optimization for stable reusable UI components
- Component tests with Testing Library and Vitest
- GitHub Actions CI for automated test and production-build checks

## Run
```bash
npm install
npm run dev
```

## Test and build
```bash
npm test
npm run build
```
